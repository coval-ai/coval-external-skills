# Covi

Use these skills when an external coding agent should delegate a read-only Coval evaluation or
troubleshooting subtask to Covi.

Connect the agent to the official remote MCP server at `https://mcp.coval.dev/mcp` with OAuth. The
skill only improves delegation behavior; the MCP server remains the source of capabilities and
authorization.

- [Consult Covi](./consult-covi/): Delegate organization-grounded Coval FDE analysis while the
  parent agent retains control of all mutations and confirmations.
